Professional landing page developed to promote IPTV subscription plans with a modern design focused on user experience and conversion.

This project was built using pure HTML, CSS and JavaScript, with an emphasis on performance, responsive design and direct customer acquisition through WhatsApp.

- Mobile First Layout
- WhatsApp Integration

- Fast Loading

- Modern User Interface

## 🛠 Technologies

- JavaScript
- Netlify

- Mobile Devices

## 🎯 Objective

Create a high-converting landing page capable of generating leads through WhatsApp and improving customer acquisition.
